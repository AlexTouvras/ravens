# Core (dead bug / side plank) — form check

## Why this clip

Dr. Aaron Horschig (DPT) on Squat University. McGill Big 3 with a clear **side plank** (knees then full) plus curl-up and bird dog. 9:09. Confirmed via YouTube oEmbed 2026-08-23.

Backup (dead bug only, not a second file): Home Base / Mass General exercise physiologist — [Fitness Education: Dead Bug Exercise Tutorial](https://www.youtube.com/watch?v=BexZRrMtF7E) (3:49).

## Cues to steal

- Side plank: elbow under shoulder, hips stacked, spine quiet. 10-second holds; regress to knees if you wobble.
- Brace first; the point is **no extra spinal motion**, not a crunch contest.
- Bird dog: opposite hand/leg, foot only a few inches off the floor, fist tight. Sweep under without losing the brace.

## Limits / do not apply when

- Library is **dead bug / side plank**. This clip is McGill Big 3 (curl-up, side plank, bird dog) — not a dead bug. Use the Home Base backup if you want the dead-bug pattern.
- Current back pain: stop and get a clinician; this is not a rehab plan.
- Skip the “every day / crazy carryover” closer. Accessory work during the 5K block, not a new core program.
- Pregnancy: use ACOG notes under `knowledge/fitness/`; side plank and dead bug both change with the belly.
