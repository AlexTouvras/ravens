#### FIND-20261116-001

- **title:** Agent Framework Python 1.26.0 requires Copilot CLI 1.0.85 and a 30-second Hyperlight budget
- **claim:** microsoft/agent-framework python-1.26.0 (published 13 Nov 2026) requires GitHub Copilot CLI 1.0.85 or later and fails startup when that version is older or cannot be determined. A custom runtime selected by `cli_path`, `GITHUB_COPILOT_CLI_PATH`, or `COPILOT_CLI_PATH` has to be upgraded to CLI 1.0.85 or later. The release says default SDK installations already meet this minimum: the existing SDK floor, 1.0.16, bundles CLI 1.0.90. The same release interrupts cancelled Hyperlight guest execution and applies a finite 30-second execution budget by default. Guest execution requires an SDK that provides `Sandbox.interrupt_handle()`, documented for Hyperlight SDK 0.9.0 or later. Installation still permits SDK 0.8.0 and does not add a fallback for older SDKs. A larger positive finite `execution_timeout_seconds` can be set on `HyperlightCodeActProvider` or `HyperlightExecuteCodeTool`. The release also deprecates the legacy experimental `MemoryContextProvider`, `MemoryFileStore`, `MemoryStore`, `MemoryIndexEntry`, and `MemoryTopicRecord` APIs for removal after 31 Dec 2026. Existing imports remain supported and emit deprecation warnings. The stated replacement is `FileMemoryProvider` with an `AgentFileStore`, which uses a different storage layout and does not migrate existing files. This is the runtime break after the 7 Nov Python 3.11 install requirement.
- **why_it_matters:** field-card — a custom Copilot CLI below 1.0.85 will not start on 1.26.0, a Hyperlight guest now stops at 30 seconds unless that timeout is raised, and the experimental memory classes are scheduled for removal after 31 Dec 2026
