### security

#### FIND-20261109-005

- **title:** Pydantic AI decision models expand a crafted tool schema without a bound, fixed in 2.66.0
- **claim:** GHSA-484x-x9m4-62cj, published 4 Nov 2026, says pydantic-ai and pydantic-ai-slim from 2.46.0 through 2.65.0 expand a tool argument schema by resolving every `$ref` again at each place it appears. A small schema whose definitions reference one another repeatedly takes exponential time and memory on the event loop. Tools whose schemas a client can supply reach this code, most directly an AG-UI endpoint. From 2.50.0 every request expands every offered tool. One crafted schema can block the event loop for minutes and exhaust process memory. The advisory scores this 6.5 (CVSS 3.1) and says the assumed attacker is an authenticated client of that endpoint. Patched in 2.66.0. Until then, drop or limit client-submitted tools, for example by rejecting schemas that contain `$defs`. This is the new advisory. It is not the 20 Oct MCP-trace fix.
- **why_it_matters:** field-card — an AG-UI worker on pydantic-ai 2.46.0 through 2.65.0 should move to 2.66.0 before it accepts client-supplied tool schemas, or reject schemas that contain `$defs` until that upgrade
