#### FIND-20261019-002

- **title:** Agent Framework Python 1.22.0 writes persisted content that pre-1.22 workers cannot read
- **claim:** microsoft/agent-framework python-1.22.0 (published 15 Oct 2026) warns that persisted artifacts containing serialized Content or streamed response-update records are not safely shared across versions. The 1.22 runtime can read records written by earlier releases, but pre-1.22 runtimes cannot read new records containing hosted or merge_mode. The note says not to run old and new workers against the same affected store during a rolling deployment, and not to downgrade after 1.22 has written those records unless the new state is isolated or migrated. Plain session metadata and checkpoints without serialized messages, content, or response updates are unaffected. The same release adds Python 3.15 support on the core and root package only where upstream dependencies allow it. This is the persisted-state break after the filed 1.21.0 session-isolation release, not a 1.21.x patch.
- **why_it_matters:** field-card — upgrading a worker that stores chat history, session snapshots, or message-bearing workflow checkpoints to 1.22.0 means older workers must not keep writing that store, and a downgrade needs the new records kept apart
