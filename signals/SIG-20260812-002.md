# TMDL View + Model Options available in Power BI web modeling

## Why open

The July 2026 Power BI update (Microsoft Learn What’s New) adds **TMDL View on the web** so developers can script, modify, and apply semantic-model object changes in a code editor without Desktop or downloading model files, alongside **Model Options** in web modeling. Useful for service-side governance and bulk metadata edits — watch whether portfolio delivery standardizes on web TMDL before promoting a standing “prefer web TMDL when…” rule.

## Watch for

- Team decision to require Desktop vs allow web TMDL for production model changes
- Permission / ALM gaps that make web TMDL unsafe for shared workspaces
- Promote to knowledge if a durable web-vs-Desktop modeling rule emerges; else expire
