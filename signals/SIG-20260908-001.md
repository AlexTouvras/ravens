# Microsoft Agent Framework Python 1.20.0 — fail-closed approvals; session-scoped file access

## Why open

microsoft/agent-framework `python-1.20.0` (GitHub release published 2026-10-02T14:40:44Z; MIT; still active) is the first cut after 1.19.0 that changes the approval and session contract: response-stream gates and buffering, **session-scoped file-access isolation**, an `AgentExecutor` checkpoint-state `TypedDict`, and opt-in `FunctionInvocationContext` injection for skill scripts. Core changes harden approval and MCP runtime context handling, treat matched function results as terminal, require session-backed local approvals, and **fail closed** when approval bindings or agent-tool approvals cannot be resolved. Foundry hosting is marked breaking: request-scoped agent factories, persistent sandbox-isolated sessions, and parsed durable Invocations runs. The 1.19.0 rules still hold underneath: HTTP cookie persistence stays **explicit**, MCP skill archives stay **ZIP-only**, and provider-backed MCP sessions stay **per invocation**. It does **not** reopen the 1.18.0 `SecretString` wrapper, Lab-off-`core[all]`, or Foundry-checkpoint-allowlist contracts, nor the 1.17.0 sequence-only middleware / removed `agent-hooks` contract. Anyone cloning the pin should land on **1.20.0**, not exact 1.19.0. Named consumer: field-card. GitHub/OSS filters pass (named consumer, approval/session decision, primary release notes, MIT + activity). Default path: signal — evaluate / pin this month rather than a durable prefer/avoid rule. Same pin — no second SIG.

## Watch for

- A named consumer cloning or documenting the 1.20.0 path — unresolved tool approvals fail closed; do not assume a missing approval binding continues; isolate local file access per session; do not assume cookies persist by default, `.mcp` archives install, or provider MCP sessions survive across invocations
- Keep SecretString as a masked wrapper, Lab off `core[all]`, middleware sequence-only, and drop `agent-hooks`
- A follow-on that restores fail-open approvals, implicit cookie persistence, non-ZIP skill archives, or cross-invocation MCP sessions
- Promote a prefer/avoid knowledge note only if field-card adopts the pin and the 1.20.0 approval/session contract holds; else expire
