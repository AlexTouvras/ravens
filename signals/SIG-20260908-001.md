# Microsoft Agent Framework Python 1.18.0 — SecretString wrapper, Lab off core[all], Foundry checkpoint allowlist

## Why open

microsoft/agent-framework `python-1.17.0` (GitHub release published 3 Sep 2026; MIT; still active) is a breaking pin on `agent-framework-core` and `agent-framework-foundry`: it restores sequence-only agent middleware inputs and removes the experimental `agent-hooks` core extra. `python-1.18.0` (published 10 Sep 2026) is the first later cut that changes credential, Lab-extra, file-hook, and Foundry-checkpoint defaults: `SecretString` is now a masked value wrapper rather than a `str` subclass; Lab dependency resolution is isolated and Lab is removed from `core[all]`; GitHub Copilot workspace file hooks become opt-in via `enable_file_hooks`; Foundry hosting restricts checkpoint deserialization by default and lets apps register extra checkpoint types. The same 1.18.0 cut adds shared vector-store abstractions plus Azure AI Search / Redis / alpha Qdrant and PostgreSQL connectors, a maximum-duration bound and stop-reason on the tool-invocation loop, and MCP Host-history conversion for persisted AG-UI conversations. It does **not** reopen the 1.17.0 sequence-only middleware / removed `agent-hooks` contract. Anyone cloning the pin should land on **1.18.0**, not exact 1.17.0. Named consumer: field-card. GitHub/OSS filters pass (named consumer, credential/Lab/checkpoint decision, primary release notes, MIT + activity). Default path: signal — evaluate / pin this month rather than a durable prefer/avoid rule.

## Watch for

- A named consumer cloning or documenting the Foundry-hosted path — treat secrets as a masked wrapper (not a `str` subclass), do not assume Lab ships in `core[all]`, opt in file hooks, and register extra checkpoint types before deserializing them; keep middleware sequence-only and drop `agent-hooks`
- A follow-on 1.18.x / 1.19 that restores `agent-hooks`, changes the middleware input shape, or reverts the SecretString / Lab / Foundry-checkpoint defaults
- Promote a prefer/avoid knowledge note only if field-card adopts the pin and the 1.18.0 contract holds; else expire
