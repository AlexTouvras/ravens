# LangChain 1.4.0 ships first-party langchain.mcp / MCPAdapter as a stable pin

## Why open

LangChain `langchain==1.4.0` (GitHub release published 3 Sep 2026; MIT) is the first non-alpha of the 1.4 line and adds the `langchain.mcp` namespace with `MCPAdapter` as a first-party way to adapt MCP servers into LangChain tools — the same feature that shipped only as 1.4.0a2–a4 through 2 Sep — plus docs examples for runnable `langchain.mcp` usage. Named watchlist consumers (field-card / ProjectBrain / JARVIS) now have a versioned, non-`--pre` first-party adapter instead of a shifting alpha or a separate `langchain-mcp-adapters` install. GitHub/OSS filters pass (named consumers, clone-vs-build, primary release notes, MIT + activity). Default path: signal until a consumer actually pins 1.4+ or a durable "prefer `langchain.mcp` over `langchain-mcp-adapters`" rule is adopted.

## Watch for

- A named consumer installing `langchain>=1.4.0` and wiring `MCPAdapter` — then promote a prefer/avoid pin
- Interface churn in a follow-on 1.4.x that would keep this signal-only
- Expire if no consumer evaluates the release this month and no durable prefer/avoid rule emerges
