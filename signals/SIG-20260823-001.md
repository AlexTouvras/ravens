# Agent Plugins 1.0.0 — vendor-neutral Agent Skills + MCP packaging spec

## Why open

Vercel published Agent Plugins 1.0.0 (6 Aug 2026), an open spec developed with AWS, Anysphere (Cursor), GitHub, and Microsoft's and OpenAI's Technical Steering Committee that packages Agent Skills (`skills/<name>/SKILL.md`) and MCP server configs (`mcp.json`) behind one `plugin.json` manifest, loading unmodified across ChatGPT/Codex, Cursor, GitHub Copilot, Kiro, and VS Code at launch. Cross-vendor TSC backing (including Cursor) makes this a plausible successor to hand-rolled per-client skill packaging, but the spec is one week old with commands/hooks/agents handling still pending in a stated future v1.1 — not durable enough yet to change ravens' own skill-authoring guidance (`cursor-skills-portable-extension`).

## Watch for

- v1.1 (or later) adding commands/hooks/agents support, and whether Cursor's native skill format maps 1:1 onto `plugin.json`
- ProjectBrain/JARVIS or ravens itself needing to distribute a skill or MCP server across more than one client — reassess this signal first
- A second named client actually shipping support (not just TSC membership) as a real adoption signal
- Promote to knowledge only once the spec is stable and a concrete decision to package ravens/ProjectBrain skills this way exists; else expire
