# content-os — agent-agnostic daily source-scan → draft-in-voice pipeline reference

## Why open

`star23/content-os` (MIT, 97 stars, created 15 Aug 2026) is a runnable reference implementation of exactly Orbit's weekly "build in public" Write shape: scan curated newsletters/X/podcasts/news through a topic library, draft posts in a fixed voice, and adjust future picks from published-post performance pulled back via reference MCP services. Worth reading against Orbit's own pipeline before it next changes, though it leans on named third-party MCP services (Typefully, Exa) that Orbit's stack does not currently run. This complements rather than duplicates [SIG-20260812-004](./SIG-20260812-004.md) (Git-backed Hugo + AGENTS.md RSS pipeline) — that signal covers the publish/RSS side, this one covers the scan/draft side.

## Watch for
