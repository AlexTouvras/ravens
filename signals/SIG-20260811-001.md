# Cursor Google Workspace plugins — approve-gated write blast radius

## Why open

Cursor shipped Marketplace plugins that let coding agents read/write Gmail, Google Drive, and Google Calendar from the IDE. That is useful automation surface, but inbox/calendar write access is a blast-radius decision — field-card and ravens automations should treat it as human-in-the-loop / approve-gated until patterns settle.

## Watch for

- Field-card or Cursor docs specifying required approve gates for Workspace writes
- Reports of unintended mail/calendar mutations from agent runs
- Decision to allow or ban Workspace write plugins in Huginn/Muninn-related automations
- Promote to knowledge if a durable HITL rule for agent email/calendar writes emerges
