# microsoft/skills-for-fabric 0.3.21 — ontology skill renamed to ontology-cli

## Why open

microsoft/skills-for-fabric `v0.3.21` (GitHub release published 2026-11-05T19:33:30Z; MIT; still active) renames the unified Fabric Ontology skill to `ontology-cli`. Explicit `fabriciq-ontology-cli` invocations have to be replaced. Natural-language Ontology requests still route to that skill’s authoring and consumption modes. A question about a new-experience (V2) ontology goes to that ontology’s own agent endpoint, which can return a plain-language answer or grounded KQL, SQL, DAX, or Python when the language and execution target are named. During preview that path requires delegated user sign-in. Service principals are not supported. CLI authoring stays limited to legacy V1 definitions and cannot create or upgrade V2 items. V1 ontologies no longer support natural-language consumption: the skill stops without querying and says to upgrade or recreate the item in the new experience. It does not substitute a hand-written source query. The same release adds `databasehub-cli` for a read-only database-estate inventory, cross-engine health, issues and suggestions, and security-posture analysis through Entra-authenticated Fabric APIs. Named consumer: Power BI portfolio / Orbit Analytics. GitHub/OSS filters pass (named consumer, skill-id replace, primary release notes, MIT + activity). Default path: signal — evaluate this month rather than a durable prefer/avoid pin. This does not reopen expired [SIG-20260907-001](./SIG-20260907-001.md). The 0.3.17 report-skill merge stays on that expired pin.

## Watch for

- A prompt or script that still calls `fabriciq-ontology-cli` — switch the skill id to `ontology-cli`
- A V2 ontology question in preview needs a delegated user sign-in; a service principal will not do
- CLI authoring cannot create or upgrade a V2 item; V1 natural-language consumption stops instead of writing a source query
- `databasehub-cli` is a read-only estate inventory, not a modeling change
- Promote a prefer/avoid knowledge note only if a named consumer adopts the renamed skill and the V2 sign-in limit still holds; else expire
- Leave the Direct Lake, UDF, and authoring-MCP notes as they are
