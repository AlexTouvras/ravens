# Power BI PBIP + VS Code dev-loop speedups (auto-reload, direct VS Code entry)

## Why open

Microsoft's August 2026 Power BI update (Microsoft Learn What's New, published 18 Aug, updated 20 Aug 2026) adds instant-reload detection in Power BI Desktop for external PBIP project-file changes, plus a built-in entry point that opens the PBIP project directly in Visual Studio Code, alongside granular semantic-model refresh (schema-only / data-only / table-level) in the service. Relevant to the Nordic Boardroom portfolio's PBIR/TMDL authoring workflow — worth testing before treating it as the standing edit loop.

## Watch for

- Test the PBIP-external-edit auto-reload and VS Code entry point against the actual Nordic Boardroom TMDL/DAX authoring workflow
- Confirm no regressions moving edits between VS Code and Desktop, and that granular refresh behaves as documented in the service
- Promote to knowledge if this becomes the standing "edit TMDL in VS Code, let Desktop reload" rule; else expire
