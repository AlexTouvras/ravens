# SEP-2640 "skills over MCP" discovery draft keeps changing shape

## Why open

The MCP "Skills Over MCP" working-group draft (SEP-2640) replaced its archive-based `skill://index.json` discovery document (13 Jul 2026) with a `skills/list` / `skills/get` capability that returns per-file `resources` manifests with `sha256:` digests. Microsoft's `Microsoft.Agents.AI.Mcp` 1.18.0-alpha (18 Aug 2026) still implements the older shape, so it is incompatible with a server written to the current draft, per a 20 Aug 2026 practitioner write-up. This corroborates ravens' own standing guidance to prefer plain, file-based Cursor Agent Skills over serving skills through an MCP server while this draft is still moving — not yet a new decision, just a reason to keep waiting.

## Watch for

- SEP-2640 reaching a stable/final discovery shape (or a pinned commit worth targeting)
- Tier-1 SDKs (Microsoft, official MCP reference servers) converging on the same shape
- Any concrete ProjectBrain/JARVIS/ravens plan to serve skills over MCP — reassess this signal first
- Expire if no further draft churn or adoption pressure surfaces within the window
