# microsoft/skills-for-fabric 0.3.17 — powerbi-report-cli merge; FabricIQ MCP host/header move

## Why open

microsoft/skills-for-fabric `v0.3.17` (GitHub release published 17 Sep 2026; MIT) is the first Fabric skill-pack cut since 0.3.16 that changes the clone-vs-wire choice: the four Power BI report skills (`powerbi-report-authoring`, `powerbi-report-design`, `powerbi-report-management`, `powerbi-report-planning`) are replaced by a single `powerbi-report-cli` skill that picks planning / design / authoring / management mode from the request — pins of those four names must switch. FabricIQ’s MCP endpoint moves from `https://api.fabric.microsoft.com/v1/mcp/fabricaihub/integrations/m365` to `https://fabriciq.svc.cloud.microsoft/v1/mcp/fabriciq` and the routing header from `X-VARIANTS: Fabric.Routing.PowerBIDataExploration` to `X-VARIANTS: Fabric.Routing.FabricIQ.V1` (existing tokens still work; hand-registered clients must re-register). `ResolveReportIdFromUrl(url)` is replaced by `ResolveFabricItem(fabricItemId=)`. The cut also adds `skills/semantic-model-authoring` field-parameter guidance, restores Azure CLI sign-in for the new FabricIQ host, and rewrites Claude Desktop registration from unpublished `@anthropic/mcp-proxy` to pinned `mcp-remote`. Anyone cloning the pack should land on **0.3.17**, not exact 0.3.16. Named consumer: Power BI portfolio / Orbit Analytics. GitHub/OSS filters pass (named consumer, clone-vs-wire, primary release notes, MIT + activity). Default path: signal — evaluate this month rather than a durable prefer/avoid pin. This is an install/endpoint/skill-name pin, not a new modeling language.

## Watch for

- A named consumer cloning or wiring **0.3.17+** — pin `powerbi-report-cli` instead of the four report skills, re-point FabricIQ MCP to the new host/header, reuse Azure CLI for remote MCP, and keep single-skill APM install
- A follow-on 0.3.x that retracts the report-skill merge, the FabricIQ host move, single-skill APM install, or Azure CLI reuse
- Expire if no consumer evaluates the release this month and no durable prefer/avoid rule emerges
