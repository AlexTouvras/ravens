# Cursor Automations — /automate, GitHub/Slack triggers, computer use default

## Why open

Cursor 3.8 (18 Jun 2026 changelog) lets local agents create Automations via `/automate`, adds Slack emoji triggers plus five GitHub triggers (issue comments, PR review comments, review submitted, review thread updated, workflow run completed), and enables **computer use by default** so cloud agents can produce demos/artifacts. Relevant to field-card HITL approve-gate patterns and ravens Huginn/Muninn / PR-triggered agents — still product-surface churn until durable HITL rules settle.

## Watch for

- Explicit field-card guidance on when computer-use demos are required vs banned in automations
- Production incidents from default-on computer use or emoji-triggered runs
- Whether ravens itself should move Huginn/Muninn from cron-plus-push-trigger onto Cursor's newer event-driven **Subscriptions** + `/goal` (see `.state/ARCHITECTURE.md` cron/push decision) before the next schedule change
- Promote a durable HITL / trigger-allowlist note if patterns stabilize; else expire at 14 days
