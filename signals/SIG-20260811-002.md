# Copilot in Excel can snapshot-analyze Power BI reports

## Why open

Microsoft documents attaching a Power BI report to Copilot in Excel so the agent answers questions and inserts editable tables/charts from a one-time snapshot. Fabric data access in Microsoft 365 Copilot is admin-gated and results do not live-refresh — relevant for executive storytelling paths that bypass pure Power BI consumption.

## Watch for

- Admin enablement status in target Microsoft 365 tenants
- Whether snapshot staleness breaks exec decision use-cases
- Durable guidance on when Excel Copilot vs Power BI report is the right delivery surface → promote
- Expire if the feature stays niche with no portfolio consumer pull
