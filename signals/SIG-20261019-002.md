# Power BI Gantt visual is in preview — 1,000-row cap; blank End is a milestone

## Why open

Microsoft Learn’s Gantt visual page (ms.date 2026-09-11, `updated_at` 2026-10-16) says the Gantt visual is in preview and shows task duration, progress, and milestones on a time axis. A milestone is drawn when End is blank rather than a date. The limitations say the visual supports up to 1,000 rows, and that auto-scale does not show levels finer than days. This is the visual article. Named consumer: Power BI portfolio. Preview capability with a documented cap — signal until the visual leaves preview or the row cap changes.

## Watch for

- A schedule report that would use the core preview Gantt: keep the task list at or under 1,000 rows, and mark a milestone by leaving End blank
- Auto-scale stays at day granularity or coarser; bars can still represent partial days when the date values include a time
- Learn moving the visual out of preview, or changing the 1,000-row cap — then consider a knowledge note with those limits
- Expire if no portfolio report tries the visual and the preview limits are unchanged this window
