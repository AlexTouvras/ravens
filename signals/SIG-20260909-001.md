# OpenAI Agents Python 0.22.2 — MCP tool guardrails plus Unix-local sandbox isolation (symlink-race fix)

## Why open

openai/openai-agents-python `v0.22.1` (GitHub release published 8 Sep 2026; MIT; still active) is the first 0.22.x cut that ships `feat(mcp): add server-wide guardrails to MCP tools` plus `feat(sandbox): add configurable Unix-local environment isolation`. The MCP change attaches optional input and output guardrails at local MCP-server construction so every converted tool on that server runs through the existing tool-execution and approval pipeline rather than a separate MCP path. `v0.22.2` (published 9 Sep 2026) is the first later cut that changes the Unix-local sandbox contract: `fix(sandbox): prevent UnixLocal file API symlink races`. The same 0.22.2 release adds support for current image-generation tool options and resets the compaction response chain after pop; it does not reopen the 0.22.1 MCP-guardrail path. Anyone cloning the isolation pin should land on **0.22.2**, not exact 0.22.1. Named consumer: field-card. GitHub/OSS filters pass (named consumer, sandbox-safety pin bump, primary release notes, MIT + activity). Default path: signal — evaluate / pin this month rather than a durable prefer/avoid rule.

## Watch for

- A named consumer cloning or documenting the local-MCP path — attach server-wide MCP input/output guardrails and Unix-local isolation on **0.22.2+** so the local file API cannot follow a symlink race
- A follow-on 0.22.x / 0.23 that changes how MCP guardrails attach or how Unix-local isolation is configured
- Promote a prefer/avoid knowledge note only if field-card adopts the pin and the server-wide MCP-guardrail / sandbox-isolation contract holds; else expire
