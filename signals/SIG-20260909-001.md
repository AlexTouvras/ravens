# OpenAI Agents Python 0.22.1 — server-wide MCP tool guardrails and Unix-local sandbox isolation

## Why open

openai/openai-agents-python `v0.22.1` (GitHub release published 8 Sep 2026; MIT; still active) is the first 0.22.x cut that ships `feat(mcp): add server-wide guardrails to MCP tools` plus `feat(sandbox): add configurable Unix-local environment isolation`. The MCP change attaches optional input and output guardrails at local MCP-server construction so every converted tool on that server runs through the existing tool-execution and approval pipeline rather than a separate MCP path. The same release also lets callers customize output-guardrail blocked messages, supports image results from web-search tools, and includes fail-closed / replay-ownership / Chat Completions pairing fixes. Named consumer: field-card. GitHub/OSS filters pass (named consumer, local-MCP delivery/safety contract, primary release notes, MIT + activity). Default path: signal — evaluate / pin this month rather than a durable prefer/avoid rule.
