# Cursor remote control of local agents is on by default outside Enterprise

## Why open

Cursor’s changelog **Remote control for local agents** (6 Oct 2026) lets you see and message local agents from the Cursor iOS app. **Remote Control is on by default for everyone except Enterprise organizations.** Enterprise admins turn it on under Org settings > Security and identity > Remote control. The agent keeps running on the computer, which must stay on and online; the phone does not move the agent to the cloud, and cloud agents are not required. Pairing is: sign in on iOS, tap the computer, approve the request in the desktop app. A paired phone is another client of the machine that holds the repo. Named consumers: field-card and ravens (local agents). This is a changelog default, not a settled prefer/avoid rule, and not the expired Rollouts / Security Review watch ([SIG-20260928-001](./SIG-20260928-001.md)).

## Watch for

- A named consumer turning Remote Control off, or confirming a paired phone is an accepted client of that machine
- An Enterprise org enablement decision under Security and identity
- A change that moves the agent to the cloud, or that defaults the feature off outside Enterprise
- Promote a prefer/avoid knowledge note only if the default and the “stays on the computer” limit hold as a standing data-handling rule; else expire. Do not fold into the Rollouts signal
