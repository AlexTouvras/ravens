# DAX Lib MCP 0.1.0 writes a package’s functions into an open Desktop model

## Why open

Marco Russo’s SQLBI post of 22 Oct 2026 says the DAX Lib MCP server **0.1.0** can search the DAX Lib catalog and install a package’s user-defined functions into a Power BI Desktop model open on the same computer. The server writes the package’s original code, including format and comments, into the model. A function of the same name is replaced; the rest of the model is left alone. The server does not save the file. The install tool is marked as changing data, so most MCP clients ask before they run it. Limits on that page: **Windows x64 only**, the model must already be open in Power BI Desktop, and the model needs compatibility level **1702** or higher (the server does not raise it). There is no separate remove or update tool — installing the new version is how a package is updated. Omitting a version installs the latest published one, which can be a prerelease. The post says the server is MIT and lives at `daxlib/daxlib-mcp`. The GitHub tag v0.1.0 is older than this article; this signal is the 22 Oct article. Named consumer: Power BI portfolio. Default path: signal — try the installer this month. It does not replace the compat-1702 UDF rule, the calculation-contract rule, or the hosted-vs-local authoring-MCP choice.

## Watch for

- A portfolio model on Windows Desktop at compat 1702+ where a DAX Lib package would replace a same-named function — read the approval, then save in Desktop
- A macOS or closed-model workflow — this server does not install there
- An unspecified package version — that path can pull a prerelease
- Promote a prefer/avoid note only if the portfolio adopts the server and the overwrite / no-save limits still hold; else expire
- Leave [dax-udfs-ga-compat-1702](../knowledge/data-bi/dax-udfs-ga-compat-1702.md), [dax-contract-before-ai-measure](../knowledge/data-bi/dax-contract-before-ai-measure.md), and [powerbi-authoring-mcp-hosted-vs-local](../knowledge/data-bi/powerbi-authoring-mcp-hosted-vs-local.md) as they stand
