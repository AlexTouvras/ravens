# Power BI Copilot Summary/Narrative can read bookmark-hidden visuals

## Why open

Microsoft Learn's August 2026 Power BI update (dated 18 Aug 2026) ships "Copilot Summary and Copilot Narrative can now read visuals hidden behind bookmarks": Copilot Summary and the Copilot Narrative visual can now read visuals that are hidden by default and revealed by a display-only report bookmark, with RLS and OLS still enforced. Bookmark-as-tabs is a common pattern on churn/RFM/readmission/Nordic-equity boards; summaries that previously skipped hidden tabs will now cover the full page. This is a shipped Copilot capability landing — worth a one-time Copilot-output check on existing bookmark-tabbed reports before relying on Summary/Narrative in a stakeholder walkthrough. Not yet a durable prefer/avoid authoring rule (sibling Theme-pane/Fluent 2 default from the same update page is already knowledge).

## Watch for

- A one-time check of Copilot Summary/Narrative output on an existing bookmark-tabbed portfolio report
- A durable delivery rule (always include hidden bookmark visuals in Narrative config / never rely on Copilot for tabbed boards) → promote
- Expire if no report is checked and no authoring rule emerges
