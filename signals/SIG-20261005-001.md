# Google ADK Python 2.11.0 — workflow tools pause for approval; abort_signal cancels the run

## Why open

google/adk-python `v2.11.0` (GitHub release published 2026-10-02T00:44:26Z; notes dated 1 Oct 2026; Apache-2.0) adds an HITL and cancellation contract on top of the expired 2.9.0 pin. Tool nodes in workflows pause for user approval via `RequestInput`, the same way an `LlmAgent` does, instead of passing an error downstream. An `abort_signal` on `Runner`, `Workflow`, and nodes stops a run gracefully, and `/run_sse` cancels the run when the client disconnects. MCP SDK 2.x stays an **opt-in** path, not a silent default. The same cut adds `ModelConsultTool` (another model mid-task, capped per turn and per session) and a SQLite memory service selected with a `sqlite://` URI. This is not the experimental skill-lifecycle flag on 2.10.0, and it does not reopen [SIG-20260912-001](./SIG-20260912-001.md) (failed-node resume, GCS `local_file_root`). Named consumer: field-card. GitHub/OSS filters pass (named consumer, approval/cancel decision, primary release notes, Apache-2.0 + activity). Default path: signal — evaluate this month rather than a durable prefer/avoid rule.

## Watch for

- A named consumer wiring ADK workflows — treat tool nodes as an approval pause (`RequestInput`), and decide whether `abort_signal` plus client-disconnect cancel belongs on the run path before treating workflows as auto-running
- Keep MCP 1.x unless MCP SDK 2.x is opted in deliberately
- A follow-on that makes workflow tools fail open again, or makes MCP 2.x the default resolve
- Promote a prefer/avoid knowledge note only if field-card adopts the pin and the approval/cancel contract holds; else expire
- Do not fold this into the expired 2.9.0 resume/GCS signal
