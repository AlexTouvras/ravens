# Anthropic unifies Claude memory across chat and Cowork with default-exclude sensitive topics

## Why open

Anthropic announced on 25 Aug 2026 that Claude's memory now works the same across chat and Claude Cowork: memories are captured as topics come up (not just summarized at session end) and shared across both surfaces, with a settings view to see/edit/delete anything stored by topic. Sensitive topics (health, beliefs, and similar) are excluded from memory by default and only stored if a user explicitly opts in. This is a concrete reference pattern (default-exclude sensitive categories, explicit opt-in toggle, per-topic view/edit/delete, one shared store instead of siloed surfaces) worth comparing against how ProjectBrain/JARVIS scope what they store and who can read it — not yet a design decision for either project.

## Watch for

- Whether ProjectBrain or JARVIS memory design adopts (or explicitly rejects) a default-exclude-sensitive-topics + opt-in pattern
- Any follow-up detail on how "sensitive topic" is classified, in case it maps to a reusable rule
- Fold into a durable security knowledge note only if a named consumer actually changes its memory-storage design against this pattern
