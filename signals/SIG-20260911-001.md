# Cursor Projects — coordinator plans/delegates/returns work; shared context and Slack/schedule/PR subscriptions

## Why open

Cursor’s changelog dated **10 Sep 2026** launches **Projects** in beta (rolling out to all users): a left-nav coordinator that does not write code itself, plans the work, delegates to agents that implement it (including thousands of subagents in parallel), and brings finished work back for a human check. Each Project runs on its own cloud computer, keeps a shared file set that syncs across every cloud and local machine its agents use (research, artifacts, and how-to-test notes persist so later agents are not re-onboarded), and can subscribe the coordinator to a Slack channel, a schedule, or all PRs so it acts on those signals without a fresh prompt. This is a new product surface on top of the 2 Sep Self-Hosted Machines pin ([SIG-20260903-002](./SIG-20260903-002.md)), not a re-announce of that worker-pool changelog. Named consumers: field-card (coordinator + approve-gate) and ravens (already on cron-plus-push, not Project subscriptions). Product-surface landing — still beta; HITL / trigger-allowlist rules have not settled.

## Watch for
